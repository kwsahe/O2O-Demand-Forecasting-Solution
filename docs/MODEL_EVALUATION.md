# 모델 평가와 한계

## 평가 요약

| 구분 | 결과 | 해석 |
|---|---:|---|
| 분석 기간 | 2025-07~2026-06, 12개월 | 연간 계절성을 안정적으로 학습하기에는 짧음 |
| 학습 / 검증 | 9개월 / 마지막 3개월 | 시간 순서를 유지한 홀드아웃 백테스트 |
| Naive Last Value | MAPE 7.75% | 마지막 학습월 거래량을 검증 3개월에 반복 |
| SARIMA | **MAPE 7.49%** | 기준선 대비 0.26%p, 상대 3.39% 개선 |
| Prophet | MAPE 8.07% | 나이브 기준선보다 0.32%p 높음 |
| LightGBM | MAPE 10.96% | 학습 가능한 행이 적어 일반화 성능이 낮음 |

최우수 모델은 SARIMA지만 기준선 대비 개선 폭은 작다. 따라서 “높은 예측 정확도”보다
“동일한 시계열 홀드아웃 조건에서 세 모델과 기준선을 비교했다”는 데 의미를 둔다.

## 데이터 누수 방지

1. 마지막 3개월을 검증 구간으로 고정하고 학습 구간 이후 값은 모델 학습에 사용하지 않는다.
2. SARIMA와 Prophet은 학습 9개월만 적합한 뒤 검증 3개월을 한 번에 예측한다.
3. LightGBM의 lag 피처는 학습 구간 내부 `shift`로만 생성한다.
4. LightGBM 다단계 예측은 검증 실제값을 다음 lag로 넣지 않고 이전 예측값을 재귀적으로 사용한다.
5. 2026년 7~12월 미래 6개월 예측은 백테스트가 끝난 뒤 전체 12개월로 별도 재학습한다. 백테스트 점수와 미래 추정값을 혼동하지 않는다.

## 수요 점수 가중치 근거

수요 점수는 정답 라벨을 학습한 지도학습 모델이 아니라 설명 가능한 도메인 스코어링 모델이다.

| 지표 | 가중치 | 가설 |
|---|---:|---|
| 매매 거래 | 20% | 거래 이후 입주·리모델링 접점과 도달 가능한 고객 규모 |
| 전월세 거래 | 20% | 임차인 교체 전 부분 시공 수요 |
| 평균 거래금액 | 15% | 고단가 시공을 감당할 구매력의 대리 변수 |
| 평균 노후도 | 15% | 마감재와 설비 교체의 시급성 |
| 평균 면적 | 10% | 시공 면적과 객단가의 대리 변수 |
| 신규 입주 | 10% | 입주 전 인테리어 수요 |
| 대수선 이력 | 10% | 실제 개보수 활동이 발생한 지역 신호 |

## 가중치 민감도

각 지표의 가중치를 개별적으로 ±20% 변경한 뒤 전체 합을 1로 재정규화한 14개 시나리오를 계산했다.

| 지표 | 결과 |
|---|---:|
| 최소 순위 상관계수 | **0.9948** |
| TOP10 최소 유지율 | **90%** |
| 평균 점수 변화 최대값 | **0.874점** |
| 개별 지역 최대 순위 변화 | **12계단** |
| 재계산 점수와 저장 점수 최대 차이 | **0.005점** |

상위권 구성과 전체 순서는 안정적이지만 경계에 있는 개별 지역은 최대 12계단 움직였다.
따라서 수요 점수는 절대적인 시장 진실이 아니라 우선순위 탐색과 영업 후보군 압축을 위한 지표로 사용해야 한다.
재현 명령은 `python scripts/analyze_score_sensitivity.py`이며 상세 결과는
`data/score_sensitivity_result.json`에 저장된다.

## LLM 평가 관점

`qwen2.5:3b`는 결정론적 계산기가 아니라 확정 수치를 자연어로 설명하는 역할만 맡는다.
전체 CSV 대신 질문과 관련된 지역·단지 행, 서버가 계산한 순위·백분위만 전달한다. 낮은 온도와 고정 시드,
입력 길이 제한, 타임아웃, `<think>` 제거, 미제공 지역 특성 문장 제거를 적용했다. 모델 연결이 실패해도
지역 점수와 규칙 기반 진입 판단은 그대로 제공한다.

## 남은 한계

- 12개월 데이터와 3개월 검증 구간만으로 계절성과 경기 국면 변화까지 일반화할 수 없다.
- 단일 홀드아웃이므로 24개월 이상 확보 후 rolling-origin 검증이 필요하다.
- 수요 점수 가중치는 비즈니스 가설 기반이며 실제 견적 요청·계약 전환 라벨로 학습되지 않았다.
- Min-Max 정규화는 극단값에 민감하므로 RobustScaler와 분위수 점수 비교가 필요하다.
- 시장규모와 예상 시공비는 공식 통계가 아니라 거래량·면적·단가 가정에 기반한 참고 추정치다.
- LLM 출력은 코드 검증을 통과하더라도 의사결정의 단독 근거로 사용할 수 없다.
