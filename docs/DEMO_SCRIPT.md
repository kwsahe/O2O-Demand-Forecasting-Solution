# 2~3분 시연 시나리오

## 0:00~0:25 문제와 데이터

“인테리어 O2O 서비스가 어느 지역에 영업·마케팅 자원을 먼저 투입할지 판단하는 데이터 제품입니다.
2025년 7월부터 2026년 6월까지 매매 35만 건과 전월세 72만 건을 수집하고, 102개 지역을 비교했습니다.”

대시보드 첫 화면에서 데이터 출처와 15~20년 Old Apartment 타겟, 7개 점수 지표를 보여준다.

## 0:25~0:55 전체 분석

통계·분석 탭에서 지역별 점수 분포와 상위 지역을 보여준다.

“서로 단위가 다른 7개 지표를 Min-Max 정규화하고 도메인 가중치로 합산했습니다. 가중치를 ±20% 변경한
14개 민감도 분석에서 TOP10은 최소 90% 유지됐지만 개별 지역은 최대 12계단 움직여 한계도 공개했습니다.”

## 0:55~1:30 지역 분석

지역 분석 탭에서 `서울 강남구`를 검색한다.

“자유 입력을 바로 분석하지 않고 정규화된 102개 지역 중 하나를 정확히 선택합니다. 강남구는 전국 4위이며,
평균 거래금액과 전월세 거래, 대수선 이력이 상대적으로 높습니다. 월별 거래 흐름, 유사 지역, 상위 단지와
최근 거래를 한 화면에서 확인할 수 있습니다.”

`AI 지역 해설 생성`을 눌러 확정 지표만 전달되는 Qwen 해설을 보여준다.

## 1:30~2:05 시계열 예측

수요 예측 탭에서 MAPE 카드와 검증 표를 보여준다.

“마지막 3개월을 시간 순서대로 분리하고 SARIMA, Prophet, LightGBM을 같은 조건에서 비교했습니다.
SARIMA MAPE는 7.49%로 나이브 기준선 7.75% 대비 상대 3.39% 개선됐습니다. 개선 폭이 작고 데이터가
12개월뿐이라는 한계를 명확히 적었습니다.”

## 2:05~2:35 엔지니어링 포인트

아키텍처 다이어그램을 보여준다.

“API 페이지네이션과 재시도, 행정구역 코드 통합, 기간 단위 upsert, 원자적 CSV 저장을 구현했습니다.
Qwen 3B에는 전체 CSV를 넣지 않고 관련 행만 검색하며, 모델이 만든 미제공 원인 문장은 코드에서 제거합니다.”

## 2:35~2:50 마무리

“데이터 수집, 분석 설계, 시계열 검증, API, 프론트엔드, 로컬 LLM까지 한 제품으로 연결한 프로젝트입니다.
현재 57개 자동 테스트가 통과하며 다음 단계는 24개월 이상 데이터와 실제 전환 라벨 확보입니다.”
